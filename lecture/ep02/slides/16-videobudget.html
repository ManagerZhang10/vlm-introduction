总结

视频不能无限吃显存：整段只给 12,288 个 token

总像素 = 每帧的宽 × 高，所有帧加起来。上限 25,165,824 是从 token 预算倒推出来的；预算固定，帧数一多，每帧只能缩小。
预算从哪来
12,288 个 token
× 每个 token 管 2 帧 × 32 × 32 像素
= 25,165,824 像素
所以「总像素上限」就是「token 上限」换了个单位。
图片是一张一个上限（16,384）；视频是整段共用一个。
两个数都是 config 默认值，官方没说怎么选的；调用时可以改。
同一份预算，切给不同长度的视频
10 秒 · 20 帧
每帧 1472×832　共 11,960 token
5 分钟 · 600 帧
每帧 256×128　共 9,600 token
每一小格 = 一帧分到的像素；条的总长 = 25,165,824
10 秒视频的一帧：1472×832
5 分钟视频的一帧：256×128
同一只猫，视频越长，每帧越小越糊。
