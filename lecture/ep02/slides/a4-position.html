总结

为什么要加位置：注意力本身不分先后

注意力只看「内容像不像」。把块的顺序打乱，得到的是同一袋 token，模型分不出原图和打乱后的图。
1不加位置：两张图对模型是一样的
原图
打乱后
token 集合 { x₁, x₂, x₃, x₄ } 完全相同
2加上位置向量：每格多了「我在哪」
x₁ + E₁
x₂ + E₂
x₃ + E₃
x₄ + E₄
位置向量 E 也是学出来的，一个位置一个，形状 197 × 768
[CLS]x₁x₂…x₁₉₆
3原版还在最前面加一个 [CLS] token
可学习的空白 token，最后一层只取它去做分类，所以序列是 196 + 1 = 197。Qwen3-VL 不做分类，没有这一格。
来源：Dosovitskiy et al. 2020，An Image is Worth 16x16 Words（arXiv 2010.11929），以 ViT-B/16 为例
位置编码负责「在哪」：加到每个 token 上，模型才分得清左上角和右下角
